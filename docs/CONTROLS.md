# Controls

| Input | Action |
| --- | --- |
| Circle Pad | Move |
| C-stick | Rotate camera |
| L | Toggle target lock |
| R | Light attack |
| ZR | Heavy attack |
| B | Dodge; hold with movement to sprint |
| A | Interact, advance dialogue, restart |
| X | Use healing flask |
| D-pad | Cycle the quick-item slot |
| Y | Toggle diagnostics |
| Start | Pause |
| Select | Exit to Homebrew Launcher |
