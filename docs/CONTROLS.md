# Controls

| Input | Action |
| --- | --- |
| Circle Pad | Move |
| D-pad Left / Right | Rotate camera |
| D-pad Up / Down | Cycle the quick-item slot |
| L | Toggle target lock; call the horse in horse-enabled outdoor areas |
| R | Light attack |
| Y | Heavy attack |
| B | Dodge; hold with movement to sprint; gallop while mounted |
| A | Interact, advance dialogue, mount/dismount, or return to the latest grace after death |
| X | Use healing flask |
| Touch ACT / RIDE / DISMOUNT | Interact, ride, dismount, advance dialogue, return to grace, or begin from title |
| Touch HEAL | Use healing flask |
| Touch LOCK / CALL / CALL/LOCK | Toggle target lock or call the active horse |
| Touch DEBUG | Toggle diagnostics |
| Start | Pause |
| Select | Exit to Homebrew Launcher |

On New-family systems, C-stick camera and ZR heavy attack remain optional compatibility inputs. The CTR-001 path above is the controlling layout and requires neither control.

The bottom screen also shows the current objective and a live top-down map. The white marker is the player, its green pip shows facing, and the gold/red marker is the next objective or boss. The Reach map shows all three horses, both waterways, the red eastern ravine exit, and cyan western ascent exit. Branch maps rescale around the active route, boss, return path, and horse.

## Sunlit Reach

Defeat the Ashen Warden and press A to cross the golden transition into the
field. Approach any horse and press A (or touch RIDE) to mount it. Hold B while
moving to gallop, press A again to dismount, and press L (or touch CALL) while
unmounted to bring the last selected horse back if it is lost.

Ride through the Reach's red eastern gate for Twinfang Ravine. Ride through its
pale-cloud western gate for Cloudbreak Ascent; follow the tan zigzag on the lower map.
The horse is automatically left safely below the summit combat plateau.

All boss zones act as graces for this demo. If the player falls, A restarts the
current fight with restored health, stamina, and flasks; the Cloudbreak grace
also returns the active horse for the climb.
