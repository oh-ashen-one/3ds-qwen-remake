# Controls

| Input | Action |
| --- | --- |
| Circle Pad | Move |
| D-pad Left / Right | Rotate camera |
| D-pad Up / Down | Cycle the quick-item slot |
| L | Toggle target lock |
| R | Light attack |
| Y | Heavy attack |
| B | Dodge; hold with movement to sprint |
| A | Interact, advance dialogue, restart |
| X | Use healing flask |
| Touch ACT | Interact, advance dialogue, restart, or begin from title |
| Touch HEAL | Use healing flask |
| Touch LOCK | Toggle target lock |
| Touch DEBUG | Toggle diagnostics |
| Start | Pause |
| Select | Exit to Homebrew Launcher |

On New-family systems, C-stick camera and ZR heavy attack remain optional compatibility inputs. The CTR-001 path above is the controlling layout and requires neither control.

The bottom screen also shows the current objective and a live top-down map. The white marker is the player, its green pip shows facing, and the gold/red marker is the next objective or boss.
